# `data/` layout

```
data/
├── raw/                 inputs
│   ├── correspondence/  ← SHIPPED in-repo: small, hand-curated concordances
│   ├── GTAPWiNDC/…      third-party (see DOWNLOAD.md), NOT in git
│   ├── BEA/SAGDP/…      third-party: state GDP (SAGDP2), NOT in git
│   ├── BEA/CAGDP2.zip   third-party: county GDP for economic centroids, NOT in git
│   └── census/…         third-party: county pop centroids + Gazetteer 2023, NOT in git
├── interim/             all derived / working artefacts (NOT in git)
│   ├── economic_centroids.csv   GDP-weighted centroids (built by step 02)
│   └── IOT/…            OECD parquet, aggregated blocks, grav_fric_v3.1_RAS_*,
│                        nested_mriot_v3.1_RAS/ (the 26 files land here first)
└── final/               the 26 delivered nested_mriot_<year>.parquet, collected
                         by run_all.sh for deposit (NOT in git → Zenodo/Figshare)
```

## What is versioned in git

Only [`raw/correspondence/`](raw/correspondence/) and the two documentation files.
Everything else is either third-party (fetch via [`raw/DOWNLOAD.md`](raw/DOWNLOAD.md))
or regenerated by the pipeline.

## The hand-curated concordance (manual step, not fully automatic)

`00_concordance.ipynb` builds `data/interim/windc_oecd_concordance.csv` automatically
from the public correspondence tables. The final concordance actually consumed by
`20_aggregation.ipynb` —
`raw/correspondence/windc_oecd_concordance_handmade_cleaned_correspondence.csv` — was
then **edited by hand** (a small number of WiNDC↔OECD sectors matched manually). The
full provenance of that manual step is shipped alongside it:

- `windc_oecd_concordance.csv` — automatic output of step 00
- `windc_oecd_concordance_handmade.xlsx` — the manual editing workbook
- `windc_oecd_concordance_handmade_all_correspondences.csv` — all hand matches
- `windc_oecd_concordance_handmade_cleaned_correspondence.csv` — **the one the pipeline reads**
- `windc_oecd_concordance_handmade_new_sectors.csv`, `…_unique_*_sectors.csv` — helpers

## Auxiliary artefacts to deposit alongside the 26 tables (Zenodo/Figshare)

Produced under `data/interim/` by the pipeline and worth depositing per the data
descriptor: the sector concordance, the state-share matrix `S`, the harmonisation
multipliers (`transform_<year>.npz`), and the inter-state distance matrix.
